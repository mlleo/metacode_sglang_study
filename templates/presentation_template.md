# 과제 발표 템플릿 (5분 + 질의 2분)

> 발표는 "무엇을 했는가"가 아니라 **"무엇을 예상했고, 무엇이 달랐는가"** 를 말하는 시간입니다.
> 슬라이드를 따로 만들 필요 없습니다. 본인 과제 `README.md`를 화면에 띄우고 아래 순서로 말하세요.

## 1. 질문 (20초)
- 이번 과제에서 답하려던 질문 한 문장

## 2. 4문장 (2분)
- **I expected** … (실행 전에 적어 둔 예측. 숫자로)
- **I changed** … (바꾼 변수 하나. 나머지 고정 조건도 한 줄)
- **I measured** … (어떤 metric을, 몇 번 반복해서)
- **I found** … (결과 숫자 + 예측과의 차이)

## 3. 그래프 한 장 (1분)
- x축 / y축이 무엇인지 먼저 말하고, 그다음 모양을 설명
- "여기가 꺾이는 지점"처럼 **한 곳을 가리키며** 설명

## 4. 왜? (1분)
- 이번 회차 이론의 어떤 개념으로 설명되는가
- 가능하면 SGLang 코드의 함수 이름 하나를 연결 (예: `PrefillAdder.add_one_req`가 `NO_TOKEN`을 반환해서…)

## 5. 한계와 다음 실험 (30초)
- 이 실험으로 **말할 수 없는 것** 한 가지
- GPU 30분이 더 있다면 무엇을 돌리겠는가
